{{- /* term — wrap a vocab word to make it a clickable definition. {{< term "validity" >}}validity{{< /term >}} key + the word as it reads in prose {{< term "standard-form" >}}standard form{{< /term >}} The glossary set comes from the PAGE, not the call — see the note below. The key looks up data/glossary/.yaml (one source of truth). The button carries only the KEY — the definition text is not inlined per-word, because a definition can cross-reference other terms ([[key|display]]) and carry word lists, and those need lookup at click time from inside an already-open card. So the whole set ships once per page as a JSON blob and the client resolves keys against it (site/glossary.ts). Behavior lives in the global bundle: desktop opens a draggable window per term (site/definitions.ts), mobile replaces the top-nav panel (site/nav.ts). Only the CSS ships lazily, once per page, on pages that actually use a term. A bad key renders the plain word and logs a build warning, so a typo never breaks the page. */ -}} {{- /* WHICH SET, without a named parameter. Hugo refuses to mix named and positional arguments in one shortcode call, and the key has always been positional — so `{{< term "x" set="dnd" >}}` is a parse error, not a template problem. The page says which glossary it uses instead, once, in front matter: `glossary: "dnd"`. That is the same key partials/definitions-assets.html reads to ship the data, so a page cannot use a set it did not load. A list takes the first entry; a page with two sets and terms from both would need a real parameter, and no page has that yet. */ -}} {{- $set := "basic-logic" -}} {{- with .Page.Params.glossary -}} {{- if reflect.IsSlice . }}{{ $set = index . 0 }}{{ else }}{{ $set = . }}{{ end -}} {{- end -}} {{- $key := .Get 0 -}} {{- $glossary := index site.Data.glossary $set -}} {{- $entry := index $glossary $key -}} {{- $display := .Inner | default $key -}} {{- if $entry -}} {{- /* The set ships once per page, keyed by set name so a page can use two. */ -}} {{- $seen := printf "glossaryData-%s" $set -}} {{- if not (.Page.Scratch.Get $seen) -}} {{- .Page.Scratch.Set $seen true -}} {{- end -}} {{- if not (.Page.Scratch.Get "definitionsAssets") -}} {{- $css := resources.Get "css/definitions.css" | minify | fingerprint -}} {{- .Page.Scratch.Set "definitionsAssets" true -}} {{- end -}} {{- else -}} {{- warnf "term shortcode: no glossary entry %q in data/glossary/%s.yaml" $key $set -}} {{ $display }} {{- end -}}
