Every cell is computed: each version of the function is run on the test and its answer compared with the expected one. Greyed columns, marked "left out", are tests not in the suite. "Survives" means no test in the suite failed that broken version, so the suite would have let the bug through. The test that only checks the answer is true or false passes for every version here: it can't fail.
