Data {{ delimit $d.data "" }} becomes the code word {{ range $p := seq 1 7 }}{{ index $b (string $p) }}{{ end }}. Every check passes, so the failed checks add up to 0: no error.

The arithmetic is real: this is the code from Hamming's 1950 paper, with checks in positions 1, 2 and 4. Each check makes the count of 1s in the positions it covers even. Check bits are drawn with a dashed border, data bits solid, and flipped bits are striped. The extra overall bit makes the count of 1s across all eight even, which lets the code tell one flip, which it can fix, from two, which it can only detect.
