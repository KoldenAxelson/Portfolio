JPEG's real 8 × 8 discrete cosine transform, run in your browser on made-up blocks (each pixel value minus 128). Blue weights are negative and red positive, and stronger colour means a bigger weight; point at one to see its pattern. Keeping only the biggest weights is a simplified stand-in for JPEG's rounding step, which divides each weight by its own step size and rounds, so the small ones become zero.
