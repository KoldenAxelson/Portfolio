Live · many optimizers, one shared trail
Run:
With JavaScript on, run a population of optimizers across this landscape.
A toy, not a benchmark: two weights instead of billions, so the whole landscape fits on screen. Each dot runs real Adam on noisy gradients. With the trail, each one deposits where its loss is good, and the trail diffuses and evaporates every step, the same three knobs as a slime-mould simulation. The ringed spot is the deepest valley. A trail can also lock everyone into the wrong valley; run it a few times.
