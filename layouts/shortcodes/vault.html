{{- /* vault — a keypad passcode gate for pages that shouldn't ship readable. The protected content never appears in the built HTML. It lives as AES-256-GCM ciphertext in static/vault/.json, sealed at authoring time by `make seal` (scripts/vault-seal.go) and opened in the browser by ts/vault.ts (WebCrypto: PBKDF2-SHA256 → AES-GCM). Crawlers, view-source, and the llms/feed outputs see only this keypad. Honesty note: a 4-digit code is 10,000 guesses — this is a door lock, not a bank vault. It keeps the content out of search engines, scrapers, and casual curiosity; it will not stop a determined attacker with a script. Longer codes seal fine if a page ever needs more. Usage in a content file (the page should also set `noindex: true`, `sitemap: disable: true`, and — under /misc — `hidden: true`): {{< vault name="growgo" >}} {{< vault name="growgo" hint="Ask me for the code." >}} Params: name (required) — sealed file's base name: static/vault/.json. Checked at build time so a typo fails the build, not the visitor (same philosophy as func/front-matter.html). hint (optional) — one quiet line under the keypad label. The sealed JSON carries the code length and render mode, so the shortcode needs neither: ts/vault.ts resizes the dots row and auto-submits when enough digits are in. `render: document` (a full standalone page, e.g. the GrowGo pitch) replaces the whole document on unlock; `render: fragment` reveals into [data-vault-outlet] below the gate. */ -}} {{- $name := .Get "name" | default (.Get 0) -}} {{- if not $name -}} {{- errorf "vault shortcode: %s needs name= naming a sealed file in static/vault/." .Position -}} {{- end -}} {{- if not (fileExists (printf "static/vault/%s.json" $name)) -}} {{- errorf "vault shortcode: %s names %q, but static/vault/%s.json does not exist. Seal it first: make seal (add a target in scripts/seal.sh for a new vault)" .Position $name $name -}} {{- end -}} {{- partial "vault-gate.html" (dict "name" $name "hint" (.Get "hint" | default "")) -}}
