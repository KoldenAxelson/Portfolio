{{- /* skyrim-perk-tree — one perk constellation, drawn as a branch graph. {{ partial "skyrim-perk-tree.html" (dict "skill" "block" "taken" (slice "shield-wall") "page" $.Page) }} Params: skill (required) key into data/skyrim/perks.yaml. taken (optional) perk ids this build spends on. A taken node takes ALL its ranks — nothing here models a partial Armsman, because no build on this page wants one. page (required) used only for the build warning on an unknown id. ── HOW IT DRAWS ──────────────────────────────────────────────────────────── Nodes are a CSS grid keyed off each perk's `tier` (row) and `lane` (column). The connectors are ONE inline SVG sitting behind that grid, absolutely positioned to fill it, with a viewBox of 100 abstract units per cell and `preserveAspectRatio="none"`. That combination is what makes it line up. The grid is sized in rem and therefore moves with the reader's font size; a connector layer measured in px would drift away from it at any zoom other than 100%. Stretching an abstract viewBox instead means the lines land on the node centres at every size, and `vector-effect="non-scaling-stroke"` keeps the stroke from being squashed by the non-uniform scale that buys us. NO JAVASCRIPT. The tree is static — it is a statement about a build, not a control. Everything here is real markup for a reader with scripting off and for anything parsing the page, which is the same reason the recipe cards are server-rendered. Edges are elbows: down out of the parent, across at the midpoint, down into the child. An edge with both ends taken is drawn in the accent; every other edge is a hairline, so the route a build walks is legible before a single label is read. */ -}} {{- $key := .skill -}} {{- $page := .page -}} {{- $taken := .taken | default slice -}} {{- $tree := index site.Data.skyrim.perks $key -}} {{- if not $tree }}{{ errorf "skyrim-perk-tree: %q is not in data/skyrim/perks.yaml" $key }}{{ end -}} {{- $perks := $tree.perks -}} {{- /* Position lookup, and the two extents the layers are sized from. `add 1` because tier and lane are 0-based and a count is not. */ -}} {{- $at := dict -}} {{- $lanes := 1 -}} {{- $tiers := 1 -}} {{- range $perks -}} {{- $at = merge $at (dict .id (dict "tier" .tier "lane" .lane)) -}} {{- if ge .lane $lanes }}{{ $lanes = add .lane 1 }}{{ end -}} {{- if ge .tier $tiers }}{{ $tiers = add .tier 1 }}{{ end -}} {{- end -}} {{- /* Warn on an id in `taken` that this tree does not have. Silent would mean a build quietly spending points on a perk that is not there. */ -}} {{- range $id := $taken -}} {{- if not (index $at $id) -}} {{- warnf "skyrim-perk-tree: %q is not a perk in the %s tree (page: %s)" $id $key $page.RelPermalink -}} {{- end -}} {{- end -}}
