{{- /* skyrim-assets — ship skyrim.css and the page bundle, once, on pages that use a Skyrim widget. A page that never mentions Skyrim never downloads a byte of this. CALLED FROM THE LAYOUT, NOT FROM THE SHORTCODES, and that is the whole point. It used to be called by each of the five shortcodes and deduplicated with a `.Scratch`-backed "have I already emitted this?" flag. That is unsound, and it failed in a way that cost real time to pin down: the page would come back unstyled and inert after any edit, and only a full `make dev` restart fixed it. Two things combine. A Page's `.Scratch` — and its `.Store`, which is NOT reset per rebuild either, whatever you may assume — survives a dev-server rebuild, so the flag stays true from the previous build. And Hugo caches rendered shortcode output, so on a rebuild only the shortcode you actually touched re-renders; that one finds the flag already set and emits nothing, while the other four serve cached markup that never contained the tags. Net effect: no stylesheet, no script, no error. Emitting once from the layout has no flag to go stale and no cache to fall out of. It also drops the guard that used to wrap skyrim-verify.html, since the partial now runs exactly once per page by construction. NOTE: partials/puzzle-assets.html and shortcodes/term.html still use the old Scratch-guarded shape and have the same latent bug. Call with the page: {{ partial "skyrim-assets.html" . }} Style only (no behaviour needed): {{ partial "skyrim-assets.html" (dict "page" . "styleOnly" true) }} */ -}} {{- $page := . -}} {{- $styleOnly := false -}} {{- if reflect.IsMap . -}} {{- $page = .page -}} {{- $styleOnly = .styleOnly -}} {{- end -}} {{- /* Data invariants, asserted once per page. This builds a dict with `merge` inside a 732-iteration loop, so running it per shortcode was five quadratic passes over 183 ingredients for one answer — which is why it was behind the old guard. */ -}} {{- partial "skyrim-verify.html" $page -}} {{- $css := resources.Get "css/skyrim.css" | minify | fingerprint -}} {{- if not $styleOnly -}} {{- $js := resources.Get "scripts/pages/skyrim/main.ts" | js.Build (dict "minify" true "target" "es2018" "format" "iife") | fingerprint -}} {{- end -}}
