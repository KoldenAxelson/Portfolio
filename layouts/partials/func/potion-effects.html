{{- /* func/potion-effects — what a set of ingredients actually brews. {{ $effects := partial "func/potion-effects.html" (slice "canis-root" "hanging-moss") }} Takes ingredient SLUGS and returns the ordered slice of effects the mixture carries. Skyrim's rule is the whole of it: an effect reaches the bottle when TWO OR MORE of the ingredients share it. A fourth effect nobody planned for is normal — see Nord Blood, where Fly Amanita and Mora Tapinella quietly both carry Regenerate Stamina. Order is first appearance, which reads the way you would say the recipe aloud. Counting scans the flat list rather than accumulating into a dict, because `merge` normalises map keys and these are Title Case names with spaces in them. Twelve effects at most, so the nested scan costs nothing. */ -}} {{- $all := slice -}} {{- range . -}} {{- with index site.Data.skyrim.ingredients . -}} {{- range .effects }}{{ $all = $all | append . }}{{ end -}} {{- end -}} {{- end -}} {{- $shared := slice -}} {{- range $effect := $all -}} {{- if not (in $shared $effect) -}} {{- $count := 0 -}} {{- range $all }}{{ if eq . $effect }}{{ $count = add $count 1 }}{{ end }}{{ end -}} {{- if ge $count 2 }}{{ $shared = $shared | append $effect }}{{ end -}} {{- end -}} {{- end -}} {{- return $shared -}}
