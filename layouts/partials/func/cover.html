{{- /* cover — build-time image optimizer for cover/badge thumbnails. Takes a cover path (as written in front matter, e.g. "/covers/foo.webp") plus a target CSS width, finds the matching SOURCE under assets/, and returns an optimized WebP resource resized for that slot — with a 2× variant for retina. All processing happens at build time (Hugo's Go image pipeline); the browser only ever receives finished, static files. Nothing client-side. ROBUSTNESS: Hugo's image pipeline can only resize RASTER formats it can decode (PNG / JPEG / WebP / GIF / TIFF / BMP). It CANNOT process SVG (vector) or AVIF — calling .Resize/.Fill/.Fit on those errors out and breaks the whole build. This template ships SVG example covers, so we guard: we only run the pipeline when the resolved resource exists AND is a processable raster. Otherwise we return the ORIGINAL path (base-path aware via func/url) with an empty srcset, so the caller renders the source image unchanged and SVG/AVIF/missing covers degrade gracefully instead of failing the build. Sources must live under assets/ (Hugo cannot read static/). A leading "/covers/" or "/badges/" path maps to the same folder under assets/; ".avif" is normalized to ".webp". WHY THE SAME FILE SITS IN BOTH assets/ AND static/. It looks like duplication and is not. This partial returns a FINGERPRINTED url — /covers/foo_hu.webp — which is right for an and wrong for metadata: og:image, twitter:image and the JSON-LD `image` fields are absolute urls handed to crawlers and cached by whoever shares the page, and they must not change every time the source does. Those consumers point at the plain "/covers/foo.webp" written in front matter, and that path resolves out of static/. Delete the static copy to tidy up and every social card and structured-data image 404s, quietly, months later. assets/ feeds the pipeline; static/ backs the stable url. Params (dict): path — cover path string from front matter (required) width — target rendered width in px (required; 2× emitted for srcset) height — target rendered height in px (optional). When set, the image is cropped to exactly width×height (Hugo Fill) — use for the square thumbnails. When omitted, the image is scaled by width preserving its aspect ratio (Hugo Resize) — use for the landscape strip. fit — when true with width+height set, scales to fit INSIDE the box without cropping (Hugo Fit) — use for badges, which shouldn't be cropped. Ignored unless height is also set. stretch — when true with width+height set, scales to exactly the box, distorting the aspect ratio (Hugo Resize WxH) — use for a row of near-uniform covers that must line up. Ignored unless height is set. q — WebP quality 0–100 (optional, default 80) retinaOnly — when true, emits only the 2× image, with no srcset; width and height still report the 1× size for the box. One file per image instead of two, for small slots like shelf covers where the browser scaling 2× down on a 1× screen costs nothing visible. noUpscale — when true (width-only), never emits a size wider than the source: a source no wider than the slot is shipped as it is, and the 2× is dropped when the source can't fill it. Used for the drawer images, whose sources are often smaller than the slot. Returns a dict: { src, srcset, width, height }. For the raster path all four are populated; for the SVG/AVIF/missing fallback, srcset/width/height are "". Callers MUST treat an empty srcset as "omit the srcset attribute". {{ $c := partial "func/cover.html" (dict "path" .Params.cover "width" 120) }} {{ with $c.src }}{{ end }} */ -}} {{- $path := .path -}} {{- $width := int .width -}} {{- $height := .height -}} {{- $fit := .fit | default false -}} {{- $stretch := .stretch | default false -}} {{- $q := .q | default 80 -}} {{- $isRetinaOnly := .retinaOnly | default false -}} {{- $noUpscale := and (.noUpscale | default false) (not $height) -}} {{- $out := dict -}} {{- with $path -}} {{- /* Map front-matter path → assets/ source. Strip leading slash, swap .avif → .webp (AVIF sources are pre-converted to webp in assets/). */ -}} {{- $rel := strings.TrimPrefix "/" . -}} {{- $rel = replace $rel ".avif" ".webp" -}} {{- $res := resources.Get $rel -}} {{- $sub := "" -}} {{- with $res -}}{{- $sub = .MediaType.SubType -}}{{- end -}} {{- $processable := and $res (not (eq $sub "svg")) -}} {{- $isSmallSource := and $processable $noUpscale (le $res.Width $width) -}} {{- if $isSmallSource -}} {{- /* Resizing to the source's own width would only re-encode it, and a 2× would be a blow-up with no extra detail. */ -}} {{- $img := $res -}} {{- if ne $sub "webp" }}{{ $img = $res.Resize (printf "%dx webp q%d" $res.Width $q) }}{{ end -}} {{- $out = dict "src" $img.RelPermalink "srcset" "" "width" $img.Width "height" $img.Height -}} {{- else if $processable -}} {{- $1x := "" -}} {{- $2x := "" -}} {{- if $height -}} {{- $h := int $height -}} {{- if $stretch -}} {{- $1x = $res.Resize (printf "%dx%d webp q%d" $width $h $q) -}} {{- $2x = $res.Resize (printf "%dx%d webp q%d" (mul $width 2) (mul $h 2) $q) -}} {{- else if $fit -}} {{- $1x = $res.Fit (printf "%dx%d webp q%d" $width $h $q) -}} {{- $2x = $res.Fit (printf "%dx%d webp q%d" (mul $width 2) (mul $h 2) $q) -}} {{- else -}} {{- $1x = $res.Fill (printf "%dx%d webp q%d" $width $h $q) -}} {{- $2x = $res.Fill (printf "%dx%d webp q%d" (mul $width 2) (mul $h 2) $q) -}} {{- end -}} {{- else -}} {{- $1x = $res.Resize (printf "%dx webp q%d" $width $q) -}} {{- $2x = $res.Resize (printf "%dx webp q%d" (mul $width 2) $q) -}} {{- end -}} {{- /* Only the variant we RelPermalink gets published: Hugo writes a processed image to disk on first .RelPermalink, not on .Resize. */ -}} {{- $isTooSmallFor2x := and $noUpscale (lt $res.Width (mul $width 2)) -}} {{- if $isRetinaOnly -}} {{- $out = dict "src" $2x.RelPermalink "srcset" "" "width" (div $2x.Width 2) "height" (div $2x.Height 2) -}} {{- else if $isTooSmallFor2x -}} {{- $out = dict "src" $1x.RelPermalink "srcset" "" "width" $1x.Width "height" $1x.Height -}} {{- else -}} {{- $out = dict "src" $1x.RelPermalink "srcset" (printf "%s 1x, %s 2x" $1x.RelPermalink $2x.RelPermalink) "width" $1x.Width "height" $1x.Height -}} {{- end -}} {{- else -}} {{- /* SVG / AVIF / missing source: pass the original path through unchanged (base-path aware) so the caller still renders it. No srcset/dims. */ -}} {{- $out = dict "src" (partial "func/url.html" $path) "srcset" "" "width" "" "height" "" -}} {{- end -}} {{- end -}} {{- return $out -}}
